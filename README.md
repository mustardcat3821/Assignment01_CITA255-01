\## What it does



The user types in a number for the amount of days they want converted to hours and days. After clicking the convert button the user receives their
time converted into said hours and minutes displayed underneath the button.



\## How to run it



Open the .sln in Visual Studio, set the target to Windows Machine, press F5.



\## Known issues



The program crashes when you type in letters to the entry box.

The program also crashes when nothing is entered into the entry box.
